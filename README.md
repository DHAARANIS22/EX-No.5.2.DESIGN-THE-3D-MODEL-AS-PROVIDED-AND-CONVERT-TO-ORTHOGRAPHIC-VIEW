# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:16-11-2026

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Open Autodesk Fusion 360 and create a new design by selecting File → New Design.
   <img width="1092" height="692" alt="Screenshot 2026-11-16 191810" src="https://github.com/user-attachments/assets/e302fadc-2c6c-4306-8e17-7cce06b7f338" />


3. Select Create Sketch and choose the XY Plane to draw the top surface of the table.
   <img width="442" height="653" alt="Screenshot 2026-11-16 010723" src="https://github.com/user-attachments/assets/13112b78-a747-447a-8929-dd8d43c1dfd2" />


5. Use the Rectangle tool to draw a square of dimensions 30 mm × 30 mm.
   <img width="43" height="46" alt="Screenshot 2026-11-16 014652" src="https://github.com/user-attachments/assets/05f2a9ec-e0a3-4259-b081-aba9f19c9613" />


7. Apply the required dimensions using the Sketch Dimension (D) tool to ensure accuracy.
   <img width="70" height="57" alt="Screenshot 2026-11-16 014210" src="https://github.com/user-attachments/assets/9d2c90d1-f9af-46a0-a782-416b353b628c" />


9. Click Finish Sketch and select the Extrude tool to give a thickness of 4 mm to the tabletop.
    <img width="142" height="66" alt="Screenshot 2026-11-16 015045" src="https://github.com/user-attachments/assets/78973778-2604-47c8-8460-11194ef2d278" />
   <img width="50" height="57" alt="Screenshot 2026-11-16 192108" src="https://github.com/user-attachments/assets/3543aba1-c0bd-49d6-b9e0-d1b6756f7d79" />
   <img width="305" height="341" alt="Screenshot 2026-11-16 021239" src="https://github.com/user-attachments/assets/7881973f-7e28-4e1e-a5ce-c425bffdc959" />


11. Select the bottom face of the tabletop and create a new sketch using the Rectangle tool to draw a leg profile of dimensions 2 mm × 2 mm.
    <img width="43" height="46" alt="Screenshot 2026-11-16 014652" src="https://github.com/user-attachments/assets/02f93b1f-8eec-4e11-aef1-c9c665905593" />


13. Use the Extrude tool to extend the leg downward to a height of 30 mm.
    <img width="43" height="46" alt="Screenshot 2026-11-16 014652" src="https://github.com/user-attachments/assets/263150e4-1f65-4fdd-99c1-6ba688f8d9bf" />


15. Repeat the same procedure for the remaining three legs using the Rectangular Pattern tool or by creating individual sketches and extrusions at the four corners.
    <img width="261" height="470" alt="Screenshot 2026-11-16 194133" src="https://github.com/user-attachments/assets/32893e6a-a2d6-4c6b-9cee-551136834b7f" />
    <img width="312" height="201" alt="Screenshot 2026-11-16 194108" src="https://github.com/user-attachments/assets/6d7306a7-9a47-4117-9c2b-6a5fc67c6470" />



17. Ensure that all four legs are positioned properly at the corners of the tabletop.

18. Use the Orbit, Pan, and Zoom tools to inspect the completed 3D table model from different directions.

19. Switch from Design Workspace to Drawing Workspace by selecting Design → Drawing → From Design.
    <img width="1092" height="692" alt="Screenshot 2026-11-16 191810" src="https://github.com/user-attachments/assets/8628582d-c688-45be-9d1c-103512fbae86" />


21. Select the required drawing standard, sheet size, and orientation.

22. Select the Base View tool and place the front view of the table on the drawing sheet. Adjust the required scale and orientation.

23. Select the Projected View tool and click the base view to generate the top view, side view, and isometric view.

24. Arrange all the orthographic views properly on the drawing sheet and click Finish.

25. Save the completed 3D model and orthographic drawing using the Save option.
